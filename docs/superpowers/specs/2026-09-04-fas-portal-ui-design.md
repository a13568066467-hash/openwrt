# FAS 认证页深色门户 UI

日期: 2026-09-04  
状态: 已批准（用户选方案 2 + 实现方式 A）

## 目标

美化 captive portal 登录页与认证成功中间页；成功后经网关放行再进入用户中心。

## 约束

- 内联 HTML/CSS（Go `fas` 包），不依赖外网字体 CDN（walled garden 拦外网）
- 登录成功：`opennds_auth?tok=rhid&redir=用户中心(token)`
- 与 user-web 品牌名「NDS」一致，视觉为深色星空门户，非用户中心浅蓝 H5

## 页面

1. **登录/注册**：星空底、NDS 品牌、主 CTA「登录上网」、注册默认折叠
2. **成功中间页**：同视觉 + 短动画，约 1.2s 后跳转放行 URL
3. **流量用尽**：同壳，跳转充值页
